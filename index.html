  • If your server only lets approved devices sign in, an administrator allows Icefin Player once (Dashboard → Devices).
  • Controllers, audio passthrough and HDR: see the install guide.

Set up

Each platform needs its repository added once. After that, every Icesuite app installs and updates from it.

Flatpak

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak remote-add --user --if-not-exists icesuite-test https://stealthx3.github.io/icesuite-test/flatpak/icesuite-test.flatpakrepo

Flathub supplies the runtimes (KDE, GNOME, freedesktop) the apps use. Remove later with flatpak remote-delete --user icesuite-test (uninstall its apps first).

Had the old icefin-test remote? Point it here, or replace it:

flatpak remote-modify --user --url=https://stealthx3.github.io/icesuite-test/flatpak/repo/ icefin-test
# or: flatpak remote-delete --force --user icefin-test && flatpak remote-add --user icesuite-test https://stealthx3.github.io/icesuite-test/flatpak/icesuite-test.flatpakrepo
