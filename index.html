Icefin Player test repository

Alpha and test builds of Icefin Player as a Flatpak remote
These are test builds: everything is checked in a virtual lab, not yet on testers' hardware. Expect rough edges, and please report problems in Issues. Current build: 0.1.0-alpha.2 + main df7291a (2026-11-12; every build on main is published here; changes since alpha.2).

Install

  1. Add Flathub, which provides the KDE runtime Icefin needs (skip this if you already have it): 
    flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
  2. Add this test repository: 
    flatpak remote-add --user --if-not-exists icefin-test https://stealthx3.github.io/icefin-flatpak-test/icefin-test.flatpakrepo
  3. Install Icefin Player: 
    flatpak install --user icefin-test io.github.stealthx3.IcefinPlayer
  4. Run it from your app menu, or: 
    flatpak run io.github.stealthx3.IcefinPlayer

One step instead of 2 and 3: flatpak install --user https://stealthx3.github.io/icefin-flatpak-test/io.github.stealthx3.IcefinPlayer.flatpakref. Software centres (GNOME Software, KDE Discover) also open the .flatpakref file.

Update

flatpak update --user io.github.stealthx3.IcefinPlayer

New test builds arrive through the same remote; flatpak update on its own updates everything.

If you installed a bundle before

A build installed from a .flatpak bundle has no remote to update from. Point it at this repository once:

flatpak install --user --reinstall icefin-test io.github.stealthx3.IcefinPlayer

Your settings and server sign-in stay; they live in ~/.var/app/io.github.stealthx3.IcefinPlayer.

Remove

flatpak uninstall --user io.github.stealthx3.IcefinPlayer
flatpak remote-delete --user icefin-test

Notes

  • Icefin installs beside Flathub's Jellyfin Desktop: its own app ID, settings and data.
  • If your server only lets approved devices sign in, an administrator allows Icefin Player once (Dashboard → Devices).
  • Controllers, audio passthrough and HDR: see the install guide.
